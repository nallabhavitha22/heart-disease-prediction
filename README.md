# Heart Disease Prediction System

A Machine Learning based web application that predicts the risk of heart disease using patient health parameters. The project integrates a trained LightGBM model with a Flask REST API to provide real-time predictions and risk analysis.

---

## Features

- Heart Disease Risk Prediction
- REST API Integration using Flask
- Machine Learning Model using LightGBM
- Real-time Prediction Responses
- Data Preprocessing and Feature Engineering
- JSON-based API Requests and Responses
- Model Evaluation and Performance Analysis
